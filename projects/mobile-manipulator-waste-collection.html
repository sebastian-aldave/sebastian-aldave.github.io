Mobile manipulator for waste collection

Academic project · Universidad Nacional de Ingeniería, Lima · Robot Analysis and Control course · Sep – Dec 2023

  • Mobile robotics
  • PID
  • C++
  • Kinematics

Project description

A 2-DOF manipulator arm mounted on a mobile platform to collect waste, with a PID controller validated under external disturbances.

  • Designed and integrated a 2-DOF manipulator arm on a mobile platform.
  • Developed a PID controller in C++ coupled with forward and inverse kinematics in MATLAB.
  • Validated the robustness of the PID controller by applying external disturbances.
